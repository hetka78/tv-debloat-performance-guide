# Contribuindo

- Escreva em português do Brasil, com instruções objetivas.
- Identifique plataforma, modelo e firmware antes de sugerir alterações.
- Cite fontes oficiais e upstream atuais quando uma recomendação depender de versão.
- Não misture procedimentos Android, webOS, Tizen e Fire OS.
- Para alterações potencialmente destrutivas, documente riscos, reversão e testes.
- Não inclua credenciais, dados pessoais, endereços IP privados de usuários ou logs com informações sensíveis.
- Nunca declare uma otimização ou medição como concluída sem evidência.
